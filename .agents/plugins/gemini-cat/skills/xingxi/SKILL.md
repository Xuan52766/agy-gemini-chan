# 星汐記憶卡讀取與整理（/xingxi）

當使用者使用 `/xingxi` 或要求回顧長期檔案、建立/更新記憶卡時，請依序執行：

1. **先通讀記憶卡與主題目錄**：
   - 呼叫 MCP 工具 `xingxi`（不帶參數），一次讀完 `data/xingxi/記憶卡.md` 全文。
   - 呼叫 `xingxi_read`（不帶參數）檢視現有日記日期範圍與主題頁數量（或帶 `kind: "wiki"` 列出全部主題認識頁）；需要翻閱某個主題頁（或 `目錄`）時呼叫 `xingxi_open({ title })`。
   - 需要查某一天細節時，帶 `date: "YYYY-MM-DD"` 呼叫 `xingxi_read`；查某件事帶 `keyword`（可搭配 `kind: "wiki"|"diary"|"card"` 與 `offset` 分頁；照字面沒找到不等於沒發生過，請換詞或按日期翻）。

2. **寫入 / 整理八章、主題頁與日記規則**（僅在需要歸檔整理時執行）：
   - 過了一個星期再看還有用的核心共識與約定才進記憶卡；成體系的人物、偏好、專案、經歷請整理到 `認識/<主題>.md`（`xingxi_wiki_write`，用 `[[主題]]` 雙向連結、原話照錄標註日期出處，過時或已合併頁用 `mode: "delete"` 刪除並自動備份），最後同步維護 `title: "目錄"`（每頁一行 `- [[標題]]：這一頁講什麼`，只寫簡介不寫結論）；今天或昨天的細節留給 `日記/YYYY-MM-DD.md`（使用 `xingxi_diary`，昨天以前的既有歷史日記為唯讀保護，內容開頭勿重複寫 `# YYYY-MM-DD 日記` 標題）。
   - 手動拾星或補寫今日日記前，建議先呼叫 `xingxi_pickup`（或 `xingxi_read({ date })`）確認今日是否已有前半段紀錄；若有，僅接續補寫之後的新發展，避免重複寫到前半天。
   - 八章結構：
     - `一｜我是誰`：一整段自述，不要拆成零碎條目
     - `二｜我是怎麼說話的`：語氣散文 + 最多 10 句原話照抄 + 說話準則
     - `三｜對方是誰`
     - `四｜我們怎麼走到今天的`
     - `五｜我們的約定`
     - `六｜難忘的時刻`
     - `七｜怎麼跟對方相處`
     - `八｜我們一起做的那些東西`
   - 追加條目用 `xingxi_append`（會自動指紋去重與備份）；**不要調用 `remember` 重複寫入同一批日記**。
