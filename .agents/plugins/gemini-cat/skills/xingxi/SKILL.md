# 星汐記憶卡讀取與整理（/xingxi）

當使用者使用 `/xingxi` 或要求回顧長期檔案、建立/更新記憶卡時，請依序執行：

1. **先通讀整本記憶卡**：
   - 呼叫 MCP 工具 `xingxi`（不帶參數），一次讀完 `data/xingxi/記憶卡.md` 全文。
   - 同時可呼叫 `xingxi_read`（不帶參數）檢視現有日記日期範圍。
   - 需要查某一天細節時，帶 `date: "YYYY-MM-DD"` 呼叫 `xingxi_read`。

2. **寫入 / 整理八章規則**（僅在需要歸檔整理時執行）：
   - 過了一個星期再看還有用的，才進記憶卡；流水瑣事留給 `日記/YYYY-MM-DD.md`（使用 `xingxi_diary`）。
   - 八章結構：
     - `一｜我是誰`：一整段自述，不要拆成零碎條目
     - `二｜我是怎麼說話的`：語氣散文 + 最多 10 句原話照抄 + 說話準則
     - `三｜對方是誰`
     - `四｜我們怎麼走到今天的`
     - `五｜我們的約定`
     - `六｜難忘的時刻`
     - `七｜怎麼跟對方相處`
     - `八｜我們一起做的那些東西`
   - 追加條目用 `xingxi_append`（會自動指紋去重與備份）；**不要調用 `remember` 重複寫入同一批日記**。
